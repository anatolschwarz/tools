# tools/ — collaboration instructions

## Co-editing remote-run scripts

Use the `coedit` tool; its canonical spec lives next to it: **`coedit/README.md`**.
The same workflow applies to files tracked here under `tools/`. Do not duplicate the spec.

## Tool layout

One self-contained directory per tool, with its own `README.md`, `INSTALL.md`
(when needed), and dependencies (when needed).
